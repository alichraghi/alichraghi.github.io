# Custom 88×31 buttons

PNG and GIF files are the website assets. The Iran and Zionist buttons
also have editable SVG sources. Their lettering uses vector pixel shapes
and does not depend on installed fonts.

- `blender-get.gif`: supplied Blender button, linked to https://www.blender.org/.
- `iran`: Lion and Sun flag artwork from the Iran Flag Project:
  https://iranflag.org/downloads/Flag-of-Iran.svg (retrieved 2026-10-11).
  Its original emblem is preserved within the custom button.
- `israel`: geometric flag drawing with blue bands and a Star of David,
  labeled ZIONIST.

- `islam.png`: the two supplied crossed-out symbols combined side by side
  on a white background, using the original images. No SVG source is kept.

The active Console design and its saved snapshot include the buttons.

To export an edited SVG to PNG, use `rsvg-convert -o button.png button.svg`.
Keep the SVG canvas at 88×31 and display the PNG at its native size.
